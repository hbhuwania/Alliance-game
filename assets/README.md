# assets

Put your family alliance photo here as **`d-alliance.png`** (or `.jpg` and update the
`<img src>` / `og:image` in `index.html`).

When `assets/d-alliance.png` exists, the game automatically shows your real photo on
the home screen instead of the built-in "D-Alliance" card — no code changes needed.

Easiest way (no git): on GitHub, open this `assets` folder → **Add file → Upload files**
→ drop your image named `d-alliance.png` → **Commit**. GitHub Pages redeploys in ~1 min.

Recommended: portrait image, up to ~1200px wide, keep it under ~1 MB.
